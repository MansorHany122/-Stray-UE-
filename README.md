# 《Stray迷失》UE场景全流程 

获课：jzit.top/26866/《Stray迷失》UE场景全流程 

拆解《Stray 迷失》UE场景：九龙城寨风格巷弄的空间叙事底层逻辑
很多玩家通关《Stray》之后，都会对游戏里的城寨巷弄留下极其深刻的印象：明明是一个虚拟构建的赛博朋克风格空间，走在里面却像真的踏入了九龙城寨的肌理里，每一条巷子的走向、每一处转角的细节都充满了真实的生活感，完全没有普通游戏场景常见的“为了好看而堆砌”的悬浮感。这种极强的沉浸感，本质上不是靠堆砌大量复古道具实现的，而是UE场景团队完全吃透了九龙城寨的空间叙事逻辑，把真实城寨里“生长出来的混乱感”完整复刻到了虚拟引擎当中。

传统的游戏巷弄场景设计，往往是先规划好清晰的主路和辅路，所有巷道横平竖直，边界清晰规整，走起来完全没有迷路的可能。但真实的九龙城寨巷弄，从来不是规划出来的，而是几十年里无数住户自发搭建、慢慢挤出来的空间。《Stray》的场景团队没有用传统的网格布局逻辑，而是采用了“自下而上的生长式设计”：先确定几个核心的公共节点，比如底层的小便利店、高处的空中平台、连接不同楼层的狭窄楼道，再从这些节点出发，自然延伸出弯曲、分叉、宽窄完全没有规律的巷道，最后所有巷道自然连通，形成一个整体空间。

这种设计思路带来的最直观体验，就是玩家在巷子里行走时，完全不会有走在“游戏预设路径”里的感觉。你随便拐进一个看起来很窄的小巷，走几十米之后会自然连通到另一条主巷道，很多看似走不通的死胡同，转个弯就会发现藏着一个向上的简易楼梯，完全复刻了真实城寨里“处处有惊喜”的空间体验。很多玩家在游戏里闲逛时，经常会在巷子里迷路，却又不会产生烦躁感，反而像在真实的陌生老城区里探索，这种感觉就是空间叙事成功的最好证明。

UE引擎强大的动态遮挡能力，在这套空间设计里发挥了核心作用。团队没有把所有巷道的空间一览无余地展示给玩家，而是用大量交错的建筑体块、外挂的空调外机、横七竖八的水管电线做天然遮挡，玩家站在巷道的入口，根本看不到巷子尽头的全貌，也看不到下一个转角后面的场景。每往前走几步，新的空间才会慢慢在你眼前展开，这种“逐步解锁空间”的体验，把城寨巷弄的迷宫感完全拉满，哪怕整个场景的实际面积并不大，玩家也会觉得这片区域大到走不完。

真正优秀的空间设计，从来不是给玩家铺一条一眼望到头的直线路径，而是用空间本身讲故事。《Stray》的城寨巷弄之所以能成为游戏史上的经典场景，核心就是它没有把空间当成装内容的容器，而是让空间本身就成了叙事的一部分，让玩家在行走探索的过程中，自然而然地感受到这片赛博城寨几十年的生长痕迹。
